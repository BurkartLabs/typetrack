# typetrack roadmap

Built for fast, accurate typists: the aim is finding the next 10 wpm, not fixing errors.
Everything works offline in the browser unless it is under **Online**.

**Navigation:** test · train · games · stats · profile

## Words

- Much larger word lists, built from public frequency data (not monkeytype's lists)
- **Standard tests use common words only**; rare and long words live in hard modes, drills and games
- Top 200 / 1k / 10k tiers per language
- Quotes from public-domain literature
- Themed packs: programming, medicine, legal
- Custom text: paste an article, a chapter, your own code
- Books mode: type through a whole book across sessions, remembering your place

## Test

- Hard modes: rare words, punctuation, capitals, numbers, code
- Quotes mode
- Pace caret at PB + 5%
- Stamina tests (3–5 min)
- No-backspace mode
- Look-ahead limit (only the next N words visible)

## Stats

- Slowest letter pairs
- Slowest words, ranked by speed
- Keystroke rhythm chart
- Hesitations, marked on the text
- Burst vs sustained speed
- Consistency score
- Collapse the error panel on clean runs; show timing analysis instead

## Train

- Pair drills built from your slowest pairs
- Memory mode
- Blind run
- Mirror mode (reversed or scrambled words)
- Metronome (score on even keystroke spacing)
- Training plans ("+10 wpm in 4 weeks") with a daily drill set

## Games

- Sprint: one short phrase, instant retry
- Ghost race: your personal best, keystroke by keystroke
- Ghost league: your last 10 PBs at once
- Treadmill: target speed rises until you fall behind
- Word bomb: each word must beat your average speed
- Word ladder: a shrinking time window per word
- Survival: one error ends the run
- Chain combo: multiplier for every word over target speed
- Falling words (elite tier)
- Typing racer: live wpm drives a car against PB-based opponents
- Tower climb: each floor harder, minimum speed to pass
- Laser defense: type a word to fire at its enemy
- Boss fight: speed deals damage, hesitations heal the boss
- Tetris-style stacking: typed words become falling blocks
- Code golf typing: symbols count double
- Duel: two players, one keyboard or split screen
- Daily gauntlet: the same 5 seeded games for everyone, one attempt, streak counter

## Languages

- Language picker: Spanish, French, German, Portuguese, Italian, Dutch, Polish, …
- Separate stats per language
- Strict or lenient accents (`e` for `é`)
- Accent drills (`ñ ç ü ø`) and a layout hint for special keys
- Cyrillic and Greek
- Right-to-left: Arabic, Hebrew
- Chinese, Japanese, Korean: needs a rethink of the engine; romanised mode first
- Vocabulary mode: target-language word with its translation underneath
- Translation race: see English, type the target language
- Mixed-language runs
- Games use the chosen language
- Code packs: JavaScript, Python, C#, SQL, Rust, shell

## Profile

- Personal bests per mode, with date and replay
- Badges and milestones
- Level / XP from characters typed
- Daily and weekly goals
- Streak calendar

## Replays

- Watch any past run, adjustable speed
- Two runs side by side

## Settings

- Theme editor: accent, background, font, caret style
- Sounds: key clicks, error sound
- Keyboard layouts: Dvorak, Colemak, custom
- Focus options: hide timer, hide live wpm, text width

## Tools

- Keyboard tester
- Input latency check
- CSV export alongside JSON

## Online (needs accounts and a server)

- Leaderboards, global and friends
- Live multiplayer races
- Shared ghosts
- Weekly tournaments

## Start with

1. Bigger common-word lists, and the language picker
2. Slowest letter pairs and pair drills
3. Pace caret and ghost race
4. Typing racer, chain combo, daily gauntlet
